## 15. セキュリティ

確認：2026年9月

```choices
rows:
  - role: 依存の脆弱性
    default: "**Renovate＋各言語の監査ツール**（§2参照）"
    tools: [renovate]
  - role: シークレット漏洩検出
    default: "**gitleaks**（lefthookとCIの両方）＋ GitHub Secret Scanning"
    tools: [gitleaks]
  - role: SAST（静的解析）
    default: "**CodeQL**（GitHub標準）"
    tools: [codeql]
    alts:
      - tools: [semgrep]
        when: 独自ルールを書きたいとき
  - role: コンテナ・IaCスキャン
    default: "**Trivy**"
    tools: [trivy]
  - role: DAST（動的診断）
    default: "**OWASP ZAP**"
    tools: [owasp-zap]
    alts:
      - name: 外部の脆弱性診断サービス
        when: 納品要件にあるとき
  - role: SBOM生成
    default: "**Syft**"
    tools: [syft]
    alts:
      - name: Trivy（SBOM出力）
        tools: [trivy]
        when: イメージスキャンと1ツールにまとめたいとき
  - role: セキュリティヘッダー
    default: "**CSP・HSTSなどを設定し、Mozilla Observatoryで確認**"
    tools: [csp, mozilla-observatory]
  - role: レート制限
    default: "**Cloudflare のレート制限ルール**"
    tools: [cloudflare]
    alts:
      - name: アプリ側
        when: Valkey/Redisでトークンバケット
  - role: パスワードハッシュ
    default: "**Argon2id**（Railsは bcrypt が標準で可）"
    tools: [argon2id]
```
